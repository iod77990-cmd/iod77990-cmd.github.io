### C

- 주소값 전달 함수 계산 후 변수 값

```c
int foo(int a, int *b){
    int c;
    *b = a + 1;
    c = a - 1;
    return c;
}

int main(){
    int a = 5;
    int b = 3;
    int c = 0;
    b = foo(a, &c);
    c = foo(b, &a);
    printf("a = %d b=%d c=%d\n", a, b, c);
    return 0;
}
```

1) int main() 부터 

int a = 5; 변수 초기화

int b = 3; 변수 초기화

int c = 0; 변수 초기화

b = foo(a, &c); foo함수에 변수 a, 주소c 를 인자로 전달, a는 값만 전달하고 c는 주소값으로 수정된 값으로 변경됨 

2) foo(a, b){} a, b는 a (a)와 b (&c)를 전달받음

3) foo(a, b){} a, b는 a (b)와 b (&a)를 전달받음

4) 변수 변화표

| 단계 | 실행 코드 | foo 내부 a | 포인터 b가 가리키는 대상 | 포인터로 변경되는 값 | return 값 | main의 a | main의 b | main의 c |
|---|---|---:|---|---:|---:|---:|---:|---:|
| 초기 | `int a = 5; int b = 3; int c = 0;` | - | - | - | - | 5 | 3 | 0 |
| 1 | `b = foo(a, &c);` | 5 | main의 `c` | `c = 5 + 1 = 6` | `5 - 1 = 4` | 5 | 4 | 6 |
| 2 | `c = foo(b, &a);` | 4 | main의 `a` | `a = 4 + 1 = 5` | `4 - 1 = 3` | 5 | 4 | 3 |

```c
#define N 3 

int main(void) {
    int (*in)[N], *out, sum = 0;

    in = (int (*)[N])malloc(N * N * sizeof(int));
    out = (int *)in;

    for (int i = 0; i < N * N; i++)
        out[i] = i;

    for (int i = 0; i < N; i++)
        sum += in[i][i];

    printf("%d", sum);

    return 0;
}
```

out = (int *)in; out변수에 in대입

- static 지역변수
```c
int a = 10;
int b = 20;
int c = 30;

void func(void) {
    static int a = 100;
    int b = 200;

    a++;
    b++;
    c = a;
}

int main(void) {
    func();
    func();

    printf("a = %d, b = %d, c = %d\n", a, b, c);

    return 0;
}
```
전역변수
| a | b | c |
|---|---|---|
| 10 | 20 | 30 | 

main(){}
1) func()
2) func()

static 변수는 전역변수보다 우선 사용

1) 
| static int a | 지역 int b | 전역 int c | 전역 int a |
|---|---:|---:|---:|
| 100 찍고 101 | 201 | 101 | 10 |

static a는 함수가 끝나도 값 유지되고 프로그램 종료하면 사라짐, 사용범위는 해당 함수 내부에서만 사용

2) 
| static int a | 지역 int b | 전역 int c | 전역 int a |
|---|---:|---:|---:|
| 101 찍고 102 | 201 | 102 | 10 |

=> a = 10, b = 20, c = 102

main함수 내에서 a 는 static 변수 보다 먼저 전역 a변수를 사용

| 코드 | 사용하는 변수 | 이유 |
|---|---:|---:|
| a++ | func 함수 내부의 static | 함수 안에 지역 a가 있음 |
| b++ | func 함수 내부의 지역변수 b | 함수 안에 지역 b 가 있음, 함수가 종료가 되면 지역 b의 변수는 사라짐 |
| c = a | c는 전역변수, a는 static 변수 | 함수 안에 지역 c 변수가 없으므로 전역변수이고 static은 함수가 종료가 되어도 유지되므로 전역 a 보다 우선순위가 높은 static a 변수를 사용 |

```java
interface Flyable {
    void fly();
}

class Bird implements Flyable {
    public void fly() {
        System.out.println("새가 난다");
    }
}
```
해당 기능을 가진 객체라면 반드시 가져야 할 메서드 규격 

| 구분 | 추상 클래스 | 인터페이스 |

| 메서드 | 일반메서드 + 추상 메서드 | 추상메서드, default/static 메서드 가능 |

- 예외 상속 관계
```java
class A extends RuntimeException {}
class B extends A {}
// 클래스 B는 A클래스의 자식관계

public class YoungJin {
    public static void main(String[] args) {
        try {
            try {
                throw new B();
            } catch (A x) {
                System.out.print("1");
                throw x;
            } finally {
                System.out.print("2");
            }
        } catch (B x) {
            System.out.print("3");
        }
    }
}
```
1) try{} 에서 B 예외

2) catch(A x){} 에서 B는 A의 자식이므로 실행, System.out.print("1"); 실행, throw x; 에서 예외 던짐

3) finally{} 반드시 실행, System.out.print("2"); 실행

4) 던진 x 예외 catch(B x){} 에서 잡혀서 System.out.print("3"); 실행

=> 123

### Python

```python
num = '25214000'

if num.isdigit(): # 문자열이 숫자로만 구성되어 있으면 아래 실행
    num = num[::-1] # num배열을 처음부터 끝까지 오른쪽에서 왼쪽으로 1씩 대입(뒤집히는 결과)
    ret = ''

    for i, c in enumerate(num): # 문자열을 하나씩 꺼내면서 i에 인덱스, c에 값
        i += 1 # 인덱스값을 넣은 i는 1부터 시작

        if i != len(num) and i % 3 == 0: # i가 마지막 요소가 아니고 3의 배수이면 아래 실행
            ret += c + ',' # ret함수에 c뒤에 , 넣어 저장
        else:
            ret += c # 아니면 c 저장

    ret = ret[::-1] # ret배열을 처음부터 끝까지 오른쪽에서 왼쪽으로 1씩 대입(뒤집히는 결과)
    print(ret) # ret변수의 값 출력

else:
    print('입력한 [%s] 숫자가 아닙니다.' % num) 
```

| 2 | '0' |
| 3 | '0' |
| 4 | '4' |
| 5 | '1' |

- 리스트 객체 메서드
1) append(x) : 리스트 맨 끝에 요소 x를 1개 추가
2) insert(i, x) : 지정한 인덱스 i에 요소 x 삽입
3) extends(iterable) : 리스트 끝에 다른 반복 가능한 객체(리스트, 튜플 등)의 모든 요소를 이어 붙임
4) remove(x) : 리스트에서 값이 x인 첫 번째 요소 삭제
5) pop([i]) : 인덱스 i에 있는 요소를 리턴하고 삭제, 인덱스 지정이 없으면 마지막 요소를 꺼냄 
6) clear() : 리스트 안의 모든 요소를 삭제하여 빈 리스트로 만듦
7) count(x) : 리스트 내에 값 x가 몇 개 있는지 개수를 반환
8) sort() : 리스트의 요소들을 오른차순 또는 내림차순으로 정렬
9) reverse() : 리스트의 요소 순서를 현재 상태에서 반대로 뒤집기
10) copy() : 리스트의 복사본을 생성하여 반환
