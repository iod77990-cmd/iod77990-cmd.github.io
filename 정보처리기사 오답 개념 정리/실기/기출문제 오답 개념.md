## 기출문제 22 ~ 25년(10회차)

### 25년 1회
- Hamming Code
  - 오류검출 + 오류수정
  - 전송데이터에 여러 개의 패리티 비트를 삽입해 단일 비트 오류를 검출, 수정 
- FEC(Forward Error Correction)
  - 수신측에서 데이터 복구
  - 추가 정정 비트 필요, 지연/재전송이 필요한 환경에 적합
  - Hamming Code 가 대표 사례
- NAK(Negative Acknowledgement)
  - 오류가 있으니 다시 보내라는 신호
  - BEC 계열에 해당
- Parity Check
  - 단순 1비트 체크
  - 단일 비트 오류 검출은 가능, 수정은 불가능
- CRC(Cyclic Redundancy Check)
  - 다항식 기반 나눗셈 검사로 오류 검출
  - 단일, 버스트 오류 검출 가능
  - 네트워크 프로토콜에서 광범위하게 사용됨

- OAuth
  - 권한 위임용(Authorization)
- SSO 
  - 한번 로그인으로 여러 곳 접근
- OpenID Connect
  - OAuth + 사용자 인증 로그인

- 테스트 조건
  - 테스트를 수행하기 전 시작조건 또는 사전조건을 의미
- 테스트 데이터
  - 테스트에서 입력하거나 활용되는 값들을 의미
- 예상결과
  - 테스트 수행 후 기대되는 결과를 명시
